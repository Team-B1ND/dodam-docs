# Notion API 연동 가이드

개인정보 처리방침은 Notion 페이지를 원본으로 사용합니다. 웹 서버가 Notion API에서 본문을 읽어 `/privacy-policy`에 표시하며, API 키는 브라우저에 전달하지 않습니다.

## 1. Notion 내부 연결 만들기

1. Notion Developer Portal에서 **Build** → **Internal connections**를 열고 연결을 만듭니다.
2. 이 프로젝트에서 사용할 워크스페이스를 선택합니다.
3. 연결의 **Configuration**에서 설치 토큰을 복사합니다.
4. 개인정보 처리방침 페이지를 읽을 수 있도록 `Read content` 권한을 활성화합니다.

내부 연결은 팀 자동화에 적합하며, 공유된 페이지만 접근할 수 있습니다. 연결을 만든 뒤 대상 개인정보 처리방침 페이지에서 `•••` → `Connections` → `Add connection`을 선택해 방금 만든 연결을 추가하세요.

자세한 내용은 [Notion 내부 연결 안내](https://developers.notion.com/guides/get-started/internal-connections)를 참고하세요.

## 2. Notion 페이지 ID 확인

Notion에서 개인정보 처리방침 페이지를 열고 `•••` → `링크 복사`를 선택합니다. URL 경로 끝의 32자리 영숫자 ID를 `NOTION_PAGE_ID`로 사용합니다. 예를 들어 `https://www.notion.so/Privacy-Policy-0123456789abcdef0123456789abcdef?pvs=4`라면 ID는 `0123456789abcdef0123456789abcdef`입니다. 하이픈이 포함된 UUID 형식도 사용할 수 있습니다.

## 3. 로컬 환경변수 설정

프로젝트 루트에서 예시 파일을 복사합니다.

```bash
cp .env.example .env.local
```

`.env.local`에 실제 값을 입력합니다.

```dotenv
NOTION_API_KEY=Notion_내부_연결_토큰
NOTION_PAGE_ID=Notion_페이지_UUID
```

`.env.local`은 Git에서 제외됩니다. API 키를 코드, 커밋, 공개 이슈에 넣지 마세요. API 키는 환경변수 또는 비밀 저장소에 보관해야 합니다. [Notion 토큰 보안 안내](https://developers.notion.com/guides/get-started/handling-api-keys)

## 4. 웹에서 문서 확인

로컬 서버를 실행하고 `/privacy-policy`를 엽니다.

```bash
npm run dev
```

Notion에서 본문을 수정하면 서버가 다음 재검증 때 변경 사항을 가져옵니다. 재검증 간격은 5분이며, 첫 요청에는 이전 캐시가 잠시 표시될 수 있습니다. 환경변수가 설정된 경우에만 사이드바에 개인정보 처리방침 링크가 표시됩니다. API 버전은 `2026-03-11`이며, 세부 동작은 [Notion Markdown API 문서](https://developers.notion.com/guides/data-apis/working-with-markdown-content)를 참고하세요.

웹의 문서 제목은 Notion 페이지 제목 속성에서 가져옵니다. 본문에 같은 제목을 다시 작성할 필요는 없습니다. Notion API가 제목 없는 페이지, 빈 본문 또는 일부 블록이 누락된 본문을 반환하면 페이지는 오류를 표시합니다. 정책을 게시하기 전에 실제 처리 현황, 시행일, 연락처를 확인하세요.

## 5. 배포 환경 설정

배포 환경에도 `NOTION_API_KEY`와 `NOTION_PAGE_ID`를 서버 측 환경변수로 등록합니다. `NEXT_PUBLIC_` 접두사를 붙이지 마세요. Next.js 서버가 요청을 처리할 때 이 값으로 Notion API를 호출합니다.

## 오류 확인

- `401`: 토큰 값이 올바른지, 만료되거나 폐기되지 않았는지 확인합니다.
- `403`: 연결의 `Read content` 권한을 확인합니다.
- `404`: 페이지 ID가 맞는지, 대상 페이지가 연결에 공유됐는지 확인합니다.
