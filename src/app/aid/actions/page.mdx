# 액션 레퍼런스

AID에서 지원하는 모든 액션의 상세 레퍼런스입니다.

## CAMERA_CAPTURE

카메라로 사진을 촬영합니다.

**웹 → 네이티브 요청:**
```ts
send(Actions.CAMERA_CAPTURE);
```

**네이티브 → 웹 응답:**
```ts
{ uri: string } // 촬영된 이미지 URI
```

---

## GPS_GET

현재 기기의 GPS 위치 정보를 요청합니다.

**웹 → 네이티브 요청:**
```ts
send(Actions.GPS_GET, { accuracy: "high" });
// accuracy: "low" | "balanced" | "high"
```

**네이티브 → 웹 응답:**
```ts
interface GPSGetResponse {
  coords: {
    latitude: number;
    longitude: number;
    altitude: number | null;
    accuracy: number | null;
    altitudeAccuracy: number | null;
    heading: number | null;
    speed: number | null;
  };
  timestamp: number;
}
```

**사용 예시:**
```tsx
const { send } = useBridgeProvider();

useBridgeResponse(Actions.GPS_GET, async (data) => {
  const { coords } = data as GPSGetResponse;
  console.log(coords.latitude, coords.longitude);
  return {};
});

send(Actions.GPS_GET, { accuracy: "high" });
```

## OAUTH_GET_TOKEN

네이티브 앱에 저장된 OAuth 토큰을 요청합니다.

**웹 → 네이티브 요청:**
```ts
send(Actions.OAUTH_GET_TOKEN);
```

**네이티브 → 웹 응답:**
```ts
{ token: string }
```

**사용 예시:**
```tsx
useBridgeResponse(Actions.OAUTH_GET_TOKEN, async (data) => {
  const { token } = data as { token: string };
  setAuthToken(token);
  return {};
});

send(Actions.OAUTH_GET_TOKEN);
```

## HAPTIC

햅틱 피드백을 트리거합니다.

**웹 → 네이티브 요청:**
```ts
send(Actions.HAPTIC, { style: "success" });
```

**지원 스타일:**
```ts
type ImpactFeedbackStyle = "light" | "medium" | "heavy" | "soft" | "rigid";
type NotificationFeedbackType = "success" | "warning" | "error";
type HapticStyle = ImpactFeedbackStyle | NotificationFeedbackType | "selection";
```

**사용 예시:**
```ts
const { send } = useBridgeProvider();

send(Actions.HAPTIC, { style: "success" });   // 성공
send(Actions.HAPTIC, { style: "warning" });   // 경고
send(Actions.HAPTIC, { style: "error" });     // 오류
send(Actions.HAPTIC, { style: "light" });     // 약한 충격
send(Actions.HAPTIC, { style: "heavy" });     // 강한 충격
send(Actions.HAPTIC, { style: "selection" }); // 선택
```

## SYNC

앱 상태를 웹뷰와 동기화합니다. 주로 네이티브 → 웹 방향으로 사용됩니다.

---

## ACK

메시지 수신 확인(Acknowledgment)에 사용됩니다. 내부적으로 자동 처리됩니다.

---

## 에러 타입

```ts
type BridgeError =
  | "TIMEOUT"
  | "PERMISSION_DENIED"
  | "NOT_SUPPORTED"
  | "CANCELLED"
  | "UNKNOWN";
```
