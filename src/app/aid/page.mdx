# @b1nd/aid-kit 사용 가이드

도담 미니앱(WebView 기반 웹 앱) 개발자를 위한 가이드입니다.
브릿지 통신 / 내비게이션 / 전역 상태 / 안전 영역 기능을 제공합니다.

## 모듈 목록

| 임포트 경로 | 설명 |
|---|---|
| `@b1nd/aid-kit/bridge-kit/web` | 네이티브 앱 기능 요청 및 응답 수신 |
| `@b1nd/aid-kit/navigation` | 스택/탭 라우팅 |
| `@b1nd/aid-kit/app-state` | 전역 상태 + localStorage 자동 동기화 |
| `@b1nd/aid-kit/safe-area-provider` | 노치/홈바 안전 영역 값 제공 |
